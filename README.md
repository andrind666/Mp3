# CineMind AI Video Generator (GitHub Workflow Ready)

Proyek ini digunakan untuk membuat video storytelling otomatis berbasis AI menggunakan Gemini API, Edge TTS, Pollinations.ai, dan FFmpeg.

## Isi File Paket
- `main.py`: Kode utama generator video.
- `topics.txt`: Tempat memasukkan ide/topik video.
- `requirements.txt`: Dependensi Python.
- `.github/workflows/render_video.yml`: Konfigurasi GitHub Actions untuk render di cloud gratis.
